# Phase 7 人工审核指南

本指南帮助非技术审核者判断五页网站结构和现有零件是否适合后续客户网站。审核对象是页面结构、信息顺序、零件用途和买家路径，不是虚构公司 `Everglow Labs — Example` 的真实性。

## 一、先理解页面中的示例数据

- `Everglow Labs — Example` 是虚构名称。
- Facial skincare、Body care、Hair & scalp care 是可理解的行业示例，不代表真实供应商产品。
- Private label、Semi-custom、Custom development 是常见合作路径示例，真实范围由客户确认。
- 页面没有默认 MOQ、价格、交期、产能、设备数量或认证名称。
- `example.com` 邮箱是保留域名，不会联系真实公司。
- 审核通过后，Phase 8 才会用客户配置替换这些示例数据。

## 二、启动与打开

在仓库根目录运行：

```powershell
$env:ASTRO_TELEMETRY_DISABLED='1'
npm.cmd run dev -- --host 127.0.0.1 --port 4321
```

打开：

`http://127.0.0.1:4321/library/base-site/`

## 三、按顺序审核五页

### 第 1 步：Home

先不要看细节，只用 10 秒回答：

1. 能否看出这是护肤品制造商网站？
2. 能否看出提供 Private Label、Semi-custom、Custom Development？
3. 能否找到 Facial Skincare、Body Care、Hair & Scalp Care？
4. 能否找到 Products、Capabilities 和 Contact 的下一步？

然后审核区段顺序：定位 → 支持能力 → 合作模式 → 产品类别 → 报价所需信息 → 供应商验证 → 项目流程 → 询盘。

记录：哪些区段应删除、提前、延后或替换。

### 第 2 步：Products

确认页面是否能回答：

1. 供应商可能覆盖哪些产品类别？
2. 每个类别是否容易理解，而不是技术黑话？
3. 买家是否知道除了产品名，还要考虑配方方向、包装和声明证据？
4. 是否需要未来新增产品详情页、规格、包装选项或相关产品？

当前产品卡片是 `ProductFamilies-001`。如果你需要产品规格表、包装图库或单品详情，这代表需要新的内页零件研究，不应硬塞进现有卡片。

### 第 3 步：Capabilities

确认页面是否能回答：

1. 从询盘到生产有哪些主要阶段？
2. 每个阶段买家需要提供什么？
3. 供应商应该交付或确认什么？
4. 质量控制点是否清楚？
5. 是否缺少你常用的能力，例如研发、打样、灌装、包装、测试或出口支持？

不要审核示例工厂是否真的具备这些能力；审核这种表达结构是否适合未来填入真实客户事实。

### 第 4 步：About

确认页面是否能回答：

1. 买家为什么应该相信这家公司？
2. 工厂、研发和质量区域是否有清楚的位置？
3. 页面是否提醒认证、厂房、设备和能力需要证据？
4. 是否需要未来新增团队、历史、认证墙、工厂图库、审厂下载或视频零件？

### 第 5 步：Contact

确认页面是否能回答：

1. 新产品询盘和质量/工厂询盘是否容易区分？
2. 买家是否知道第一次联系要准备什么？
3. 是否需要真实网站加入 RFQ 表单、文件上传、WhatsApp、电话或地图？

这些交互尚未实施。若需要，应在后续阶段建立有隐私、错误处理和后端边界的正式组件。

## 四、审核三种首页方向

目前有三种已批准的首页预设：

- Premium：`/library/premium-homepage/`
- Manufacturing：`/library/manufacturing-homepage/`
- Launch：`/library/launch-homepage/`

它们是经过验证的起点，不是只能使用的固定模板。审核时判断：

1. 哪种最适合高端品牌与研发叙事？
2. 哪种最适合强调工厂、质量和采购证据？
3. 哪种最适合新品牌快速理解合作路径？
4. 是否允许从一个预设开始，再删除、增加或调整现有 sections？答案应为“允许”。

Phase 8 的客户配置系统将负责保存客户选择的首页方向、页面、sections、顺序、内容、图片、联系方式和主题。

## 五、检查手机与桌面

至少检查：

- 手机约 390px：菜单、标题换行、卡片顺序、CTA、横向滚动。
- 平板约 768px：导航状态、双列内容、信息密度。
- 桌面约 1440px：导航是否完整、页面是否过空或过密、阅读宽度是否合理。

每页还要确认：

- Header 当前页面有明显状态；
- 所有主要 CTA 都有合理目的地；
- 页面只有一个主标题；
- 图片和文字没有明显错位；
- Footer 可以再次进入主要页面和 Contact。

## 六、如何给出审核结论

可以直接复制以下格式回复：

```text

Home：保留……；删除……；顺序调整……
Products：缺少……
Capabilities：缺少……
About：缺少……
Contact：需要……
移动端问题：……
桌面端问题：……

三种首页预设：保留 / 调整……
允许客户在预设基础上自由增删和排序 sections：是 / 否
是否进入 Phase 7.5 内页零件扩展：是 / 否
是否进入 Phase 8 客户配置：是 / 否
```

只有当五页结构、导航、询盘路径和 Phase 7 新组件都可以复用时，才把 Phase 7 条目从 `Review` 改为 `Approved`。
